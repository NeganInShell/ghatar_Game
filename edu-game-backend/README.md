## معرفی

بک‌اند این پروژه با زبان **رست** و فریم‌ورک **Axum** نوشته شده است. وظیفه‌اش دادن سؤال‌های آماده هر ایستگاه، ذخیره ستاره‌ها و تاریخچه پاسخ‌های کودک است.

> اگر بک‌اند خاموش باشد، بازی با داده محلی ادامه می‌دهد؛ پس بک‌اند اختیاری است ولی برای ثبت دائمی پیشرفت لازم است.

## تکنولوژی‌ها

| ابزار | کاربرد |
|---|---|
| رست + Axum + Tokio | وب‌سرور ناهمگام |
| SQLx + SQLite | دیتابیس سبک بدون نیاز به نصب |
| rand | ترتیب تصادفی واقعی سؤال‌ها و گزینه‌ها |
| tower-http | CORS برای اتصال فرانت |
| tracing + dotenvy | لاگ و متغیر محیطی |

## اجرا

```bash
cargo run
# 🚀 Server running on http://0.0.0.0:3000
```

### متغیر محیطی

| نام | پیش‌فرض | توضیح |
|---|---|---|
| `DATABASE_URL` | `sqlite:data/edu_game.db?mode=rwc` | مسیر فایل دیتابیس |

> دیتابیس و داده‌های اولیه به‌صورت خودکار ساخته و سید می‌شوند؛ نیازی به دستور جدا نیست.

### بررسی سلامت

```bash
cargo check   # بررسی بدون هشدار
```

## داده‌های اولیه (سید خودکار)

| جدول | تعداد | توضیح |
|---|---|---|
| حروف | ۱۰ | ا، ب، د، ن، ر، س، ت، ز، م، خ |
| هجاها | ۹ | ما، با، نا، را، سا، تا، دا، زا، خا |
| کلمات | ۴۴ | بدون هیچ تکرار بین ایستگاه‌ها (آب تا نترس!) |

## API

| متد | مسیر | توضیح |
|---|---|---|
| GET | `/api/health` | سلامتی سرور |
| GET | `/api/db-check` | اتصال دیتابیس |
| GET / POST | `/api/letters` | لیست و افزودن حرف |
| GET | `/api/letters/:id` | یک حرف |
| GET / POST | `/api/syllables` | لیست و افزودن هجا |
| GET | `/api/syllables/:id` | یک هجا |
| GET / POST | `/api/words` | لیست و افزودن کلمه |
| GET | `/api/words/:id` | یک کلمه |
| GET | `/api/game/station/1..20?count=4` | ⭐ سؤال آماده هر ایستگاه (نوع + استخر مخصوص همان ایستگاه) |
| GET | `/api/game/stage/1..5?count=4` | سازگار با نسخه قدیم ۵ مرحله‌ای |
| POST / GET / DELETE | `/api/progress` ، `/api/progress/:child_id` | ثبت، خواندن و پاک‌کردن پیشرفت و ستاره‌ها (مرحله ۱ تا ۲۰) |
| POST / GET / DELETE | `/api/answers` ، `/api/answers/:child_id` | ثبت و خواندن پاسخ‌ها |
| DELETE | `/api/history/:child_id` | 🧹 پاک‌کردن کامل تاریخچه یک کودک |
