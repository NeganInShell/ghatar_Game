## 🌱 معرفی

**قطار کلمه‌ها** یک بازی آموزشی فارسی است که با آن کودک سوار یک قطار کوچک می‌شود، از ۲۰ ایستگاه رد می‌شود و قدم‌به‌قدم **ترکیب‌خوانی** را یاد می‌گیرد:

> حروف → هجا (`م + ا = ما`) → کلمه (`مادر`، `باران`، `مداد` ...)

🔤 **حروف آموزشی:** `ا، ب، د، ن، ر، س، ت، ز، م، خ`

### ✨ چرا این بازی؟

| اصل | توضیح |
|---|---|
| 🧩 ساده و بدون شلوغی | هر صفحه فقط **یک کار**، فونت خیلی درشت، دکمه‌های لمسی بزرگ |
| 💛 بدون اضطراب | بدون تایمر، بدون نمره منفی — اشتباه = «یک بار دیگه امتحان کن 🌱» |
| ⭐ تشویق واقعی | هر جواب درست = ستاره + صدای تشویق + «آفرین! عالی بود! 💖» |
| 🔁 تکرار مهربان | هر ایستگاه فقط ۴ سؤال کوتاه + دکمه 🔁 و 🔊 همه‌جا |
| 🔊 راهنمای صوتی | اول فایل صوتی معلم، اگر نبود خودکار TTS فارسی |
| 🌙 لایت / دارک | حالت روز و شب + کاملاً **ریسپانسیو** (موبایل، تبلت، دسکتاپ) |

## 🛠️ تکنولوژی‌ها

| بخش | تکنولوژی |
|---|---|
| 🦀 بک‌اند | **Rust** + Axum + Tokio + SQLx (SQLite) + rand |
| 🧡 فرانت | **Svelte 5** (runes) + Vite + Vazirmatn |
| 🗃️ دیتابیس | SQLite — حروف، هجاها، کلمات، پیشرفت، پاسخ‌ها |
| 🔊 صوت | فایل MP3 معلم ← fallback خودکار TTS فارسی + سنتز WebAudio |
| 🎨 عکس | SVG تمیز و سبک برای هر کلمه و ایستگاه |

## 🚀 اجرا

### پیش‌نیازها

- Rust (cargo) — نسخه پایدار
- Node.js 18+ و npm

### ۱️⃣ بک‌اند (پورت 3000)

```bash
cd edu-game-backend
cargo run
# 🚀 Server running on http://0.0.0.0:3000
```

> دیتابیس و ۴۴ کلمه به‌صورت خودکار seed می‌شوند: `data/edu_game.db`

### ۲️⃣ فرانت (پورت 5173)

```bash
cd edu-game-frontend
npm install
npm run dev
# ➜ http://localhost:5173
```

### 📦 بیلد نهایی فرانت

```bash
cd edu-game-frontend
npm run build
```

> اگر بک‌اند خاموش باشد، بازی با داده محلی ادامه می‌دهد (آفلاین‌فرندلی) ✅

## 🔌 API بک‌اند

| متد | مسیر | توضیح |
|---|---|---|
| GET | `/api/health` | سلامتی سرور |
| GET | `/api/letters` ، `/api/syllables` ، `/api/words` | لیست آموزشی (+ `POST` برای افزودن، `GET /:id` تکی) |
| GET | `/api/game/station/1..20?count=4` | سؤال آماده هر ایستگاه ⭐ |
| GET | `/api/game/stage/1..5?count=4` | سازگار با نسخه قدیم ۵ مرحله‌ای |
| POST / GET / DELETE | `/api/progress` ، `/api/progress/:child_id` | ثبت، خواندن و پاک‌کردن پیشرفت و ستاره‌ها |
| POST / GET / DELETE | `/api/answers` ، `/api/answers/:child_id` | ثبت و خواندن پاسخ‌ها |
| DELETE | `/api/history/:child_id` | پاک‌کردن کامل تاریخچه (پیشرفت + پاسخ‌ها) 🧹 |

## 🔊 فایل‌های صوتی

کافیست فایل `mp3` را **دقیقاً با همین اسم** در `edu-game-frontend/public/sounds/` بگذاری — اگر نباشد بازی با TTS می‌خواند:

```
sounds/letters/letter-م.mp3          ← حرف «م»
sounds/syllables/syllable-زا.mp3     ← هجای «زا»
sounds/combine/combine-ز-ا.mp3       ← «ز + ا»
sounds/words/word-خرس.mp3            ← کلمه «خرس»
sounds/praise/praise-آفرین.mp3       ← تشویق «آفرین»
sounds/guide/try-again.mp3           ← «یک بار دیگه امتحان کن»
sounds/stations/station-7-intro.mp3  ← معرفی ایستگاه ۷
sounds/effects/effect-horn.mp3       ← 📯 بوق قطار آخر مرحله
```

📋 لیست کامل ماشینی: `public/sounds/manifest.json` — راهنمای فارسی: `public/sounds/README.md`
